Release Notes

26.10.0
- Hold-to-talk voice dictation and voice commands on every screen, floating above the bottom buttons (Whisper on the station's AI server)
- Ask the station's language model general questions, with the AI model chosen from the server's list
- Choose the knowledge source for answers: lazee's RAG or Sandy Strands
- When the knowledge base has nothing, c-beam points to the data rescue probe siri, which unfortunately does not have it either
- Optionally read c-beam's answers aloud with the phone's text-to-speech, with proper pronunciation of c-base, c-beam and crew
- Show voice results as a small terminal in the activity-log style
- Show when the lists were last refreshed and update them more reliably
- Show the server's error message when a c-ontrol action fails instead of failing silently
- Fix crash when the app is reopened on the c-ontrol tab after Android killed it in the background
- Fix the unlabeled c-ontrol buttons and the Default LED pattern button
- Hide the c-ontrol buttons that no longer do anything (LED colours, speed, Software-Endlager, Darkwall); the LED pattern buttons now match what the c_leuse LEDs support

26.09.0
- Fix unsafe WebView SSL error handler (Google Play policy alert)
- Enable TLS certificate validation for c-beam and ETA server connections
- Limit unencrypted HTTP to the internal services that require it
- Raise minimum Android version to 7.1 (required for current server certificates)
- Ask for notification permission on Android 13 and newer, so notifications appear again
- Fix crash on incoming MQTT notifications on Android 12 and newer
- Fix crash when a push message arrives without a title
- Fix crash on startup on Android 7.1
- Vibrate on incoming notifications
- Fix notifications not appearing on Android 8 and newer in the F-Droid build
- Keep the user interface responsive while data is loading
